Basic 16-Bit Computer Architecture Using Logisim Evolution

Project Overview

This project presents the design and simulation of a basic 16-bit computer architecture using Logisim Evolution.

The system demonstrates how the main components of a CPU work together to execute instructions through a hardwired control unit.

Project Objectives

* Design and simulate a basic 16-bit CPU.
* Understand the interaction between CPU components.
* Implement a hardwired control unit.
* Demonstrate instruction execution and data flow.
* Explore computer organization and digital logic design.

Main Components

* Arithmetic Logic Unit (ALU): Performs arithmetic and logical operations.
* Control Unit: Generates control signals for instruction execution.
* Registers: Store temporary data and processor information.
* Memory: Stores instructions and data.
* System Bus: Transfers information between components.
* Input/Output: Supports basic communication with external components.

Technologies & Tools

* Logisim Evolution
* Digital Logic Design
* Computer Architecture
* Hardwired Control
* 16-Bit CPU Design

How to Run

1. Install Logisim Evolution.
2. Download the circuit project file from this repository.
3. Open the circuit file in Logisim Evolution.
4. Explore the CPU components and their connections.
5. Use the simulation controls to observe circuit behavior.
